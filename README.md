# 인공신경망 선박 총톤수 예측 웹 페이지

데이터처리개론 4. 인공신경망 기초 과제용 사이트입니다.

**사이트 주소:** https://jjohyun123-ctrl.github.io/Data-Processing-Assignment-2-ANN/

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 첫 페이지 (버튼 네 개) |
| `ship.html` | 선박 총톤수 예측 페이지: 데이터 정리 → 정규화 → 신경망 구조 → 학습 → 결과 비교 → 직접 예측 7단계 |
| `general.html` | 내 데이터로 예측하기: CSV/엑셀을 올리고 입력·예측 열을 골라 신경망 학습 |
| `explain.html` | 설명서 (선박 예측 / 범용 프로그램 두 칸) |
| `code.html` | 코드 설명: 파이썬 코드 2개와 ann.js를 한 단계씩 설명 |
| `style.css` | 공통 디자인 |
| `ann.js` | 인공신경망 계산 코드: 순전파, 오차 역전파, Adam 가중치 업데이트, 선형회귀(정규방정식) |
| `ship_data.js` | 웹에서 쓰는 선박 데이터 3,000척 표본 |
| `ship_tonnage_ann.py` | 선박 총톤수 예측 파이썬 코드 (원본 CSV 정리 → Keras 신경망 학습 → 선형회귀 비교 → 직접 예측) |
| `general_ann.py` | 범용 예측 파이썬 코드 (설정만 바꾸면 어떤 데이터든 예측) |
| `울산항_선박제원_정제.csv` | 이상값을 정리한 선박 데이터 54,368척 |

## 사용한 데이터

- 자료명: 울산항만공사_선박제원정보 (2026.05.27 기준)
- 출처: 공공데이터포털 (data.go.kr)
- 입력 X: 선박길이 L, 선박너비 B, 선박깊이 D (m)
- 출력 Y: 총톤수 GT

## 신경망 구조

- 입력층: 노드 3개 (길이, 너비, 깊이)
- 은닉층: `Dense(6, activation="sigmoid")`
- 출력층: `Dense(1)` (총톤수)
- 오차: 평균제곱오차(MSE), 학습: Adam (경사하강법)

## 결과 (테스트 데이터)

| 지표 | 인공신경망 | 선형회귀 |
|---|---|---|
| 결정계수 R² | 약 0.97 | 약 0.80 |

선형회귀는 길이·너비·깊이를 더하는 식이라 부피처럼 곱해지는 관계를 따라가지 못하고, 소형선을 음수 톤수로 예측하기도 합니다. 인공신경망은 시그모이드 노드를 조합해 이 비선형 관계를 학습합니다.

## 코드 실행 방법 (Google Colab)

1. Colab에서 새 노트북을 만들고 `.py` 파일의 `# %%` 단위로 셀을 나눠 붙여넣습니다.
2. 왼쪽 폴더 아이콘에 데이터 파일을 올립니다.
   - `ship_tonnage_ann.py` → 공공데이터포털 원본 `울산항만공사_선박제원정보_20260527.csv`
   - `general_ann.py` → `울산항_선박제원_정제.csv` (또는 원하는 데이터)
3. 위에서부터 차례로 실행합니다.
