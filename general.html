어떤 데이터든 인공신경망으로 예측하기

CSV나 엑셀 파일을 올리고 입력 X와 예측할 값 Y를 고르면, Dense 층으로 만든 인공신경망이 바로 학습하고 선형회귀와 비교합니다. 처음에는 울산항 선박 제원 데이터로 시작합니다.

선박 데이터로 단계별 과정과 알고리즘 설명을 보려면 선박 총톤수 예측하기로 이동하세요. 이 프로그램이 어떻게 동작하는지는 범용 프로그램 설명서에 정리했습니다.

데이터: 울산항 선박 제원 (예시)

입력 X (여러 개 선택 가능)

값을 넣어 예측하기

epoch 0 신경망 테스트 R² – 선형회귀 테스트 R² –

사용 방법

  1. "내 파일 불러오기"로 CSV나 엑셀 파일을 올립니다. 첫 줄에 열 이름이 있어야 합니다.
  2. 숫자로 된 열이 자동으로 표시되면, 입력 X로 쓸 열(여러 개 가능)과 예측할 값 Y를 고릅니다.
  3. 신경망이 바로 학습을 시작합니다. 데이터의 80%로 학습하고, 나머지 20%(테스트 데이터)로 정확도를 잽니다.
  4. "값을 넣어 예측하기" 칸에 원하는 값을 넣으면 두 모델의 예측값이 나옵니다.

공공데이터에서 흔한 cp949(EUC-KR) 인코딩, "1,234"처럼 쉼표가 들어간 숫자, 빈칸이 있는 행은 자동으로 처리합니다. 3,000행이 넘으면 브라우저 속도를 위해 3,000행을 무작위로 뽑아 사용합니다. 999999 같은 이상값은 걸러내지 않으므로, 필요하면 파일에서 미리 정리해 주세요.

테스트 R²는 1에 가까울수록 정확하고, 0이면 평균값으로 찍는 것과 같은 수준입니다.

신경망 구조

입력 X로 고른 열 하나하나가 입력 노드가 되고, 은닉층 Dense(시그모이드)를 거쳐 출력 노드 하나로 Y를 예측합니다. 열을 바꾸면 그림도 바뀝니다.

범용 코드 (Google Colab)

2번 설정 셀의 파일 경로와 열 이름만 바꾸면 어떤 데이터에도 쓸 수 있습니다. 예시는 정리된 울산항 선박 데이터(울산항_선박제원_정제.csv) 기준입니다.

결과 해석 (기본 데이터)

선형회귀는 1월에서 12월로 갈수록 기온이 조금씩 오른다는 거의 평평한 직선만 그리고, 여름에 기온이 가장 높았다가 다시 떨어지는 계절 변화를 전혀 표현하지 못합니다. 학습에 쓰지 않은 테스트 데이터로 잰 평균제곱오차(MSE)는 약 78입니다.

인공신경망은 학습이 진행될수록 곡선이 산 모양으로 휘어지며 계절 변화를 따라가고, 테스트 MSE가 약 5까지 줄어듭니다. 남은 오차는 대부분 같은 달 안에서 지점마다 기온이 다른 정도(지역 차이)라서, "몇 월인가"라는 정보 하나로는 더 줄이기 어렵습니다. 남은 오차를 더 줄이려면 위도, 고도처럼 지점의 특성을 입력 노드로 추가하면 됩니다(다차원 입력).

은닉 노드가 1~2개면 표현할 수 있는 곡선이 부족해 굴곡을 다 따라가지 못합니다. 노드를 늘리면 더 복잡한 모양을 맞출 수 있지만, 너무 많으면 잡음까지 외워버리는 과적합이 생길 수 있어 테스트 데이터의 오차로 확인해야 합니다.
