2. 설정

나중에 바꿀 수 있는 값을 맨 위에 모아 둔 셀입니다.

  • X_COLS에 열이 3개이므로 입력 노드가 3개, Y_COL이 1개이므로 출력 노드가 1개가 됩니다.
  • HIDDEN_NODES = 6: 은닉층 동그라미(노드) 개수입니다.
  • EPOCHS = 60: 학습 데이터 전체를 처음부터 끝까지 60번 반복해서 봅니다.
  • BATCH_SIZE = 256: 256척씩 묶어서 오차를 계산하고 가중치를 한 번 고칩니다. 학습 데이터가 약 43,500척이므로 1 epoch에 가중치를 약 170번 고칩니다.
  • LEARNING_RATE = 0.01: 경사하강법 식 w ← w − η·∂E/∂w 의 η입니다. 한 번에 가중치를 얼마나 크게 움직일지 정합니다.

3. 원본 데이터 불러오기

공공데이터포털 CSV는 대부분 한글 인코딩이 cp949(EUC-KR) 입니다. 그래서 cp949로 먼저 읽고, 한글이 깨져 오류(UnicodeDecodeError)가 나면 UTF-8로 다시 읽도록 try / except를 썼습니다.

raw.head()는 첫 5줄을 보여 줘서 열 이름과 값이 제대로 읽혔는지 확인하는 용도입니다. 원본은 90,604행입니다.

4. 데이터 정리 (이상치 제거)

학습 전에 잘못 기록된 값을 걸러냅니다. 각 줄 아래 print로 남은 행 수를 확인합니다.

  1. raw["사용여부"] == "Y": 현재 쓰이는 선박 기록만 남깁니다. → 86,473행
  2. df[X_COLS + [Y_COL]]: 필요한 4개 열만 남기고, (df > 0).all(axis=1)로 한 칸이라도 0인 행을 지웁니다. → 86,452행
  3. < 999999, < 999 등: 값을 모를 때 채워 넣은 999999, 999.9 같은 숫자를 지웁니다. → 83,637행
  4. (L / B).between(2.5, 10) 등: 길이/너비, 너비/깊이 비율이 실제 배 모양에서 벗어난 행을 지웁니다. 예를 들어 길이 179.9 m인데 너비 174 m로 적힌 기록이 여기서 걸러집니다. → 77,668행
  5. C = 총톤수 / (L×B×D): 총톤수는 부피에 비례하므로 이 비율이 0.15~0.8을 벗어나면 치수나 톤수 중 하나가 잘못 적힌 것으로 보고 지웁니다. → 74,930행
  6. drop_duplicates(): 같은 배가 여러 번 입항해서 똑같이 반복된 기록을 하나만 남깁니다. → 54,368행

5. 전처리 (0~1 정규화 + 학습/테스트 분리)

  • .values: 표(DataFrame)를 계산용 숫자 배열로 바꿉니다. Y는 [[Y_COL]]처럼 대괄호를 두 번 써서 세로 한 줄짜리 2차원 배열로 만듭니다. MinMaxScaler가 2차원만 받기 때문입니다.
  • fit_transform: 각 열의 최솟값·최댓값을 기억하고(fit), x′ = (x − 최솟값) / (최댓값 − 최솟값) 으로 바꿉니다(transform). 입력과 출력에 스케일러를 따로 써야 나중에 y_scaler.inverse_transform으로 예측값을 원래 톤 단위로 되돌릴 수 있습니다.
  • 정규화하는 이유: 시그모이드는 입력이 크면 출력이 0이나 1에 붙어 기울기가 거의 0이 되고 학습이 멈춥니다.
  • train_test_split(..., test_size=0.2, random_state=42): 80%는 학습용, 20%는 학습에 쓰지 않고 정확도 확인에만 씁니다. random_state=42는 실행할 때마다 똑같이 나누도록 고정하는 값입니다.

6. 인공신경망 만들기 (layer → Dense, o → node)

keras.Sequential([...])은 괄호 안의 층을 위에서부터 순서대로 쌓습니다.

코드 강의 그림에서
keras.Input(shape=(3,)) 입력층, 노드 3개 (길이, 너비, 깊이)
Dense(6, activation="sigmoid") 은닉층, 노드 6개. 각 노드가 z = w₁L′ + w₂B′ + w₃D′ + b 를 계산하고 σ(z)를 내보냄
Dense(1) 출력층, 노드 1개. 활성화 함수가 없어서 Σ v·σ(z) + c 값을 그대로 총톤수로 내보냄

출력층에 시그모이드를 쓰지 않은 이유는 0~1 사이 확률이 아니라 연속된 숫자(톤수) 를 예측하는 회귀 문제이기 때문입니다.

model.compile은 학습 방법을 정합니다. loss="mse"는 오차를 평균제곱오차 E = (1/n)Σ(y − ŷ)²로 계산하라는 뜻이고, Adam은 경사하강법을 개선한 방법으로 가중치마다 이동 폭을 자동 조절합니다.

model.summary()를 실행하면 학습되는 값의 개수가 나옵니다. 은닉층 3×6 + 6 = 24개, 출력층 6 + 1 = 7개, 합계 31개입니다.

7. 학습 + 오차 감소 그래프

model.fit이 실제 학습입니다. 순전파로 예측 → 오차 계산 → 역전파로 기울기 계산 → Adam으로 가중치 수정을 EPOCHS번 반복합니다.

  • validation_data=(X_test, Y_test): 매 epoch이 끝날 때마다 테스트 데이터의 오차도 기록합니다. 테스트 데이터는 가중치 수정에는 쓰이지 않습니다.
  • verbose=0: 학습 중 출력을 끕니다.
  • history.history["loss"], ["val_loss"]: epoch별 학습 오차와 테스트 오차 목록입니다.

그래프는 오차가 수백 배 줄어들어서 yscale("log")로 세로축을 로그 눈금으로 그렸습니다. 두 선이 함께 내려가면 잘 학습된 것이고, 학습 오차만 내려가고 테스트 오차가 올라가면 학습 데이터만 외운 과적합입니다.

8. 선형회귀와 비교

  • inverse_transform: 0~1로 바꿨던 값을 다시 원래 톤 단위로 되돌립니다. 실제값과 두 모델의 예측값 모두 되돌린 뒤 비교합니다.
  • LinearRegression().fit(X_train, Y_train): 같은 학습 데이터로 3장의 선형회귀(총톤수 = a·L + b·B + c·D + 상수)를 만듭니다.

출력되는 지표 세 가지:

지표 뜻
R² 1에 가까울수록 정확. 0이면 평균값으로 찍는 수준
평균절대오차 예측이 실제와 평균 몇 톤 차이 나는지
음수 예측 비율 톤수를 0보다 작게 예측한 비율 (물리적으로 불가능한 값)

산점도에서 가로축은 실제값, 세로축은 예측값이고, 점선 y = x에 점이 가까울수록 정확합니다.

9. 학습된 가중치 확인

model.layers는 Dense 층 2개의 목록이고, layer.get_weights()는 그 층의 [가중치 행렬 W, 바이어스 b]를 돌려줍니다.

  • 은닉층 W의 모양은 (3, 6): 행 3개가 입력(길이·너비·깊이), 열 6개가 은닉 노드입니다. 즉 W[0][2]는 "길이 → 은닉 노드 3"으로 가는 화살표의 가중치입니다.
  • 출력층 W의 모양은 (6, 1): 은닉 노드 6개 → 출력 노드 1개입니다.

강의자료에서 화살표마다 w를 세었던 것(w(9), w(3))을 실제 학습된 숫자로 확인하는 셀입니다.

10. 선박 치수를 넣어 총톤수 예측

  1. input()으로 길이·너비·깊이를 입력받고 float()로 숫자로 바꿉니다.
  2. x_scaler.transform(...): 학습 때 기억해 둔 최솟값·최댓값으로 똑같이 정규화합니다. 여기서 fit을 새로 하면 기준이 달라져 엉뚱한 값이 나옵니다.
  3. model.predict → y_scaler.inverse_transform: 신경망 출력(0~1)을 톤 단위로 되돌립니다.
  4. [0, 0]: 결과가 1×1 배열이라 그 안의 숫자 하나를 꺼냅니다.
  5. :,.0f: 천 단위 쉼표를 넣고 소수점 없이 출력합니다.

4. 전처리

선박 코드 5번과 같습니다. 입력·출력을 각각 0~1로 정규화하고 80%/20%로 나눕니다.

5. 인공신경망 만들기 + 학습

선박 코드와 다른 점은 keras.Input(shape=(len(X_COLS),)) 한 줄입니다. len(X_COLS)가 고른 열의 개수라서, 입력 노드 수가 데이터에 맞춰 자동으로 정해집니다. 열을 1개 고르면 입력 노드 1개, 5개 고르면 5개입니다.

학습되는 값의 개수는 입력 m개, 은닉 H개일 때 m×H + H + H + 1개입니다. 모델을 만들고(Sequential), 학습 방법을 정하고(compile), 학습하고(fit), 오차 그래프까지 한 셀에서 합니다.

6. 결과 비교

R²로 신경망과 선형회귀를 비교한 뒤, 입력 개수에 따라 그래프를 다르게 그립니다.

  • 입력이 1개일 때: 가로축 X, 세로축 Y인 산점도 위에 두 모델의 예측선을 그립니다. np.argsort로 X를 작은 값부터 정렬해야 선이 지그재그로 꼬이지 않고 왼쪽에서 오른쪽으로 이어집니다.
  • 입력이 여러 개일 때: 축 하나에 X를 다 그릴 수 없으므로, 가로축 실제값·세로축 예측값 그래프를 그립니다. 점선에 가까울수록 정확합니다.

7. 원하는 값을 넣어 예측하기

[... for col in X_COLS]가 고른 열 개수만큼 반복해서 값을 입력받습니다. 열이 3개면 3번, 1개면 1번 물어봅니다. 그 뒤는 선박 코드 10번과 같이 학습 때의 스케일러로 정규화하고, 예측하고, 원래 단위로 되돌립니다.

시그모이드 함수

σ(z) = 1 / (1 + e⁻ᶻ) 를 그대로 옮긴 한 줄입니다. 파이썬 코드의 activation="sigmoid"가 내부에서 하는 계산과 같습니다.

가중치 초기화 (생성자)

신경망을 처음 만들 때 가중치를 무작위로 정합니다.

  • this.W: 입력 → 은닉 가중치. 은닉 노드 H개 각각이 입력 d개에 대한 가중치를 가집니다 (H × d개).
  • this.b: 은닉 노드마다 하나씩 있는 바이어스입니다. 시그모이드가 데이터 범위 안에서 꺾이도록 초기값을 맞춰 줍니다.
  • this.v, this.c: 은닉 → 출력 가중치 H개와 출력 바이어스 1개입니다.
  • m, s, t: Adam이 기억하는 값입니다 (아래 설명).

seed를 고정해서 페이지를 새로 열어도 같은 초기값으로 시작합니다.

순전파 (예측)

  • z(j, x): 은닉 노드 j의 입력 합 z = Σ(w·x) + b
  • predict(x): 은닉 노드마다 σ(z)를 구해 출력 가중치 v를 곱해 더하고 c를 더합니다. ŷ = Σ vⱼ·σ(zⱼ) + c

Keras의 model.predict가 하는 일과 같습니다.

학습 1 epoch (역전파 + Adam)

파이썬 코드의 model.fit이 내부에서 하는 일을 직접 구현한 부분입니다.

  1. 순전파: 학습 데이터 한 척마다 은닉 출력 a[j]와 예측값 o를 계산합니다.
  2. 오차: r = Y[i] - o를 제곱해 더해 평균제곱오차를 구합니다. e = -2r/n은 오차 E를 예측값 ŷ로 미분한 값입니다.
  3. 역전파: 연쇄법칙으로 기울기를 거꾸로 구합니다.
  4. ∂E/∂vⱼ = e · aⱼ
  5. ∂E/∂zⱼ = e · vⱼ · aⱼ(1 − aⱼ) ← 여기서 aⱼ(1 − aⱼ)가 시그모이드의 미분 σ′(z)
  6. ∂E/∂wⱼₖ = ∂E/∂zⱼ · xₖ
  7. Adam 업데이트: m은 기울기의 이동평균(방향), s는 기울기 제곱의 이동평균(크기)입니다. 기울기가 계속 크게 흔들리는 가중치는 조금씩, 꾸준한 가중치는 크게 움직여서 기본 경사하강법(w ← w − η·∂E/∂w)보다 빨리 수렴합니다.

선형회귀 (정규방정식)

웹페이지에서 비교용으로 쓰는 선형회귀입니다. 최소제곱법의 해는 (XᵀX)β = XᵀY 를 풀면 바로 나오므로, 이 연립방정식을 가우스 소거법으로 풉니다. 결과 β는 [상수, L의 계수, B의 계수, D의 계수]이고, predictLinear가 β₀ + β₁L + β₂B + β₃D 를 계산합니다.

신경망과 달리 반복 학습 없이 한 번에 답이 나오는 이유가 이것입니다 (3장 선형회귀의 a, b 공식과 같은 원리).
