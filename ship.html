선박 주요 치수로 총톤수 예측하기

울산항에 입항한 선박의 길이, 너비, 깊이를 입력으로 받아 인공신경망이 총톤수를 예측합니다. 아래 단계를 하나씩 눌러 가며 데이터 정리부터 학습, 예측까지 따라가 보세요.

다른 데이터로 해보려면 내 데이터로 예측하기를 사용하세요. 전체 설명은 설명서에 있습니다.

데이터 소개

자료명울산항만공사_선박제원정보 (2026.05.27 기준)
출처공공데이터포털 (data.go.kr), 울산항만공사 선석운영지원시스템
원본 규모90,604행, 9개 열
입력 X선박길이 L, 선박너비 B, 선박깊이 D (m)
출력 Y총톤수 GT

총톤수는 선박 내부 공간의 크기를 나타내는 값이라 대략 L × B × D, 즉 부피에 비례합니다. 세 치수가 서로 곱해지는 관계이기 때문에, 각 변수에 계수를 곱해 더하기만 하는 선형회귀로는 정확히 표현하기 어렵습니다. 선박 초기 설계 단계에서 주요 치수만으로 톤수를 추정하는 문제를 인공신경망으로 풀어 봅니다.

가로축

정리된 데이터 중 3,000척을 무작위로 뽑아 표시했습니다. 치수가 커질수록 총톤수가 직선이 아니라 위로 휘어지며 급격히 커집니다.

데이터 정리

공공데이터에는 입력 실수나 빈 값을 대신한 숫자가 섞여 있습니다. 학습 전에 아래 규칙으로 걸러냈습니다. 막대를 누르면 해당 규칙의 설명이 나옵니다.

정규화

길이는 수백 m, 깊이는 수십 m, 총톤수는 수십만까지 단위가 제각각입니다. 시그모이드 함수는 입력이 너무 크면 출력이 0이나 1에 붙어 학습이 멈추기 때문에, 모든 값을 0~1 사이로 바꿔 줍니다.

x′ = ( x − 최솟값 ) / ( 최댓값 − 최솟값 )

신경망 구조

동그라미 하나하나가 노드(node), 세로 한 줄이 층(layer)입니다. 앞 층의 모든 노드가 다음 층의 모든 노드와 연결되는 층을 Dense 층이라고 합니다. 파란 은닉 노드를 누르면 그 노드가 하는 계산을 볼 수 있습니다.

은닉 노드를 눌러 보세요.

학습

예측값과 실제값의 차이를 제곱해 평균낸 오차(MSE)를 줄이는 방향으로 가중치를 조금씩 고치는 과정을 반복합니다.

E = (1/n) Σ ( y − ŷ )²　　w ← w − η · ∂E/∂w
epoch 0 오차(MSE) – 테스트 R² –
가중치는 어떻게 고쳐지나 (오차 역전파)

출력 노드에서 계산한 오차를 합성함수의 미분법으로 은닉층까지 거꾸로 전달해 모든 가중치의 기울기를 구합니다. 은닉 노드 j가 입력 xk에서 받는 가중치의 기울기는 다음과 같습니다.

∂E/∂wjk = −(2/n) Σ ( y − ŷ ) · vj · σ(zj)(1 − σ(zj)) · xk

vj는 은닉 노드 j에서 출력으로 가는 가중치이고, σ(z)(1 − σ(z))는 시그모이드의 미분입니다. 이 페이지와 Colab 코드는 경사하강법을 개선한 Adam 방식을 쓰는데, 원리는 같고 가중치마다 이동 폭을 자동으로 조절합니다.

결과 비교

인공신경망 선형회귀 점선에 가까울수록 정확

선형회귀는 총톤수 = a·L + b·B + c·D + 상수처럼 치수를 더하는 식이라, 부피처럼 곱해지는 관계를 따라가지 못합니다. 그래서 대형선은 작게 예측하고, 소형선은 아예 음수 톤수로 예측하는 경우가 생깁니다. 이 테스트 데이터에서도 선형회귀는 선박의 약 –%를 음수 톤수로 예측했습니다. 인공신경망은 시그모이드 노드 여러 개를 조합해 휘어진 관계를 스스로 만들어 내기 때문에 작은 배부터 큰 배까지 고르게 맞춥니다.
