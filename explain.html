1. 과제 개요

3장에서 배운 선형회귀는 입력 변수에 계수를 곱해 더하는 식(y = ax + b)으로 데이터를 설명합니다. 그래서 데이터가 곡선 형태이거나(비선형성) 입력 변수가 여러 개 얽혀 있으면(다차원성) 정확도가 크게 떨어집니다.

이 과제에서는 조선해양 분야의 공개 데이터인 울산항 입항 선박의 제원 정보를 이용해, 선박의 주요 치수(길이 L, 너비 B, 깊이 D)로 총톤수(GT) 를 예측하는 인공신경망을 만들고 선형회귀와 비교했습니다.

출력 Y 총톤수 GT

이 데이터를 고른 이유 총톤수는 선박 내부 공간의 크기를 나타내는 값이라 대략 L × B × D, 즉 부피에 비례합니다. 세 치수가 서로 곱해지는 관계이므로, 각 변수를 더하는 선형회귀로는 정확히 표현하기 어렵습니다. 입력이 3개라서 다차원성, 곱의 관계라서 비선형성을 동시에 보여줄 수 있고, 선박 초기 설계 단계에서 주요 치수만으로 톤수를 추정하는 실제 문제와도 연결됩니다.

3. 데이터 정리 (전처리)

공공데이터에는 입력 실수와 빈 값을 대신한 숫자가 섞여 있어, 학습 전에 다음 규칙으로 정리했습니다.

단계 규칙 남은 행 수
원본 — 90,604
1 사용여부가 Y인 선박만 사용 86,473
2 길이·너비·깊이·총톤수 중 0인 값 제거 86,452
3 999999, 999.9 같은 자리채움 값 제거 83,637
4 배 모양으로 불가능한 치수 제거 (L/B 2.5~10, B/D 0.8~4, L 10~400 m 밖) 77,668
5 총톤수 ÷ (L×B×D)가 0.15~0.8 밖인 기록 제거 (치수와 톤수가 맞지 않는 입력 오류) 74,930
6 중복 기록 제거 54,368

예를 들어 길이 179.9 m인데 너비가 174 m로 기록된 선박은 4단계에서 걸러졌습니다.

이후 모든 값을 0~1 범위로 정규화했습니다. 시그모이드 함수는 입력이 너무 크면 출력이 0이나 1에 붙어 기울기가 거의 0이 되고 학습이 멈추기 때문입니다.

x′ = (x − 최솟값) / (최댓값 − 최솟값)

정리된 데이터의 80%는 학습용, 20%는 테스트용으로 나눴습니다.

4. 인공신경망 구조

층 노드 수 코드
입력층 3 (L, B, D) keras.Input(shape=(3,))
은닉층 6 keras.layers.Dense(6, activation="sigmoid")
출력층 1 (총톤수) keras.layers.Dense(1)

그림의 동그라미 하나가 노드(node), 세로 한 줄이 층(layer) 입니다. 앞 층의 모든 노드가 다음 층의 모든 노드와 연결된 층을 Dense(완전연결) 층이라고 하며, Keras에서는 Dense로 층을 쌓습니다.

학습되는 값의 개수는 입력→은닉 가중치 3×6 = 18개, 은닉 바이어스 6개, 은닉→출력 가중치 6개, 출력 바이어스 1개로 총 31개입니다.

5. 알고리즘 설명

5-1. 노드 하나의 계산

각 노드는 입력에 가중치를 곱해 모두 더하고 바이어스를 더한 뒤, 활성화 함수 φ를 통과시킵니다. 강의자료의 "인공신경망의 기본 틀"과 같습니다.

z = w₁·L′ + w₂·B′ + w₃·D′ + b　→　출력 = σ(z)

5-2. 시그모이드 활성화 함수

σ(z) = 1 / (1 + e⁻ᶻ)　　σ′(z) = σ(z)(1 − σ(z))

활성화 함수가 없으면 층을 아무리 쌓아도 전체가 하나의 선형식이 되어 선형회귀와 같아집니다. 시그모이드는 각 노드에서 S자 곡선을 만들고, 출력층이 이 곡선들을 가중치로 더하면서 L·B·D처럼 휘어진 관계를 표현할 수 있습니다. 또한 미분값을 자기 자신으로 쉽게 계산할 수 있어 학습에 유리합니다.

5-3. 오차 정의

3장 잔차분석의 잔차제곱합과 같은 생각으로, 평균제곱오차(MSE)를 줄이는 것이 목표입니다.

E = (1/n) Σ (y − ŷ)²

5-4. 경사하강법

선형회귀는 a, b를 공식으로 한 번에 구할 수 있었지만, 신경망은 가중치가 31개이고 식이 복잡해 공식으로 풀 수 없습니다. 대신 오차를 각 가중치로 미분한 기울기를 보고, 오차가 줄어드는 방향으로 조금씩 이동하는 과정을 반복합니다.

w ← w − η · ∂E/∂w　(η: 학습률)

강의의 km→mile 예시에서 0.5 → 0.6 → 0.7 → 0.61로 값을 고쳐 가며 오차를 줄인 것과 같은 원리입니다. 학습률이 너무 크면 최솟값을 지나쳐 반대쪽으로 넘어가고, 너무 작으면 학습이 느려집니다.

5-5. 오차 역전파

출력층에서 계산한 오차를 합성함수의 미분법(연쇄법칙)으로 은닉층까지 거꾸로 전달해 모든 가중치의 기울기를 구합니다.

∂E/∂wⱼₖ = −(2/n) Σ (y − ŷ) · vⱼ · σ(zⱼ)(1 − σ(zⱼ)) · xₖ

vⱼ는 은닉 노드 j에서 출력으로 가는 가중치입니다. 실제 코드는 경사하강법을 개선한 Adam 방식을 사용했는데, 원리는 같고 가중치마다 이동 폭을 자동으로 조절해 더 빨리 수렴합니다.

7. 프로그램 구성

선박 총톤수 예측하기 (심화) 데이터 소개 → 데이터 정리 → 정규화 → 신경망 구조 → 학습 → 결과 비교 → 직접 예측의 7단계를 클릭하며 따라갈 수 있습니다. 구조도에서 은닉 노드를 누르면 그 노드의 가중치와 계산식이 나오고, 학습 단계에서는 오차가 줄어드는 과정이 실시간으로 보입니다.

내 데이터로 예측하기 (범용) (범용 프로그램 설명서 보기) CSV나 엑셀 파일을 올리고 입력 X 열(여러 개 가능)과 예측할 Y 열을 고르면 같은 구조의 신경망이 바로 학습하고 선형회귀와 비교합니다. 공공데이터에 흔한 cp949 인코딩과 쉼표 숫자를 자동 처리하며, Colab 범용 코드도 설정 셀만 바꾸면 다른 데이터에 쓸 수 있습니다.

8. 결론

선박의 길이·너비·깊이와 총톤수처럼 변수들이 곱해지는 비선형 관계에서는 선형회귀의 한계가 뚜렷했고(R² 0.80, 음수 톤수 예측), 은닉층에 시그모이드를 둔 인공신경망이 이를 크게 개선했습니다(R² 0.97). 남은 오차를 더 줄이려면 선종(유조선, 컨테이너선 등)이나 건조연도 같은 정보를 입력 노드로 추가하는 방법을 생각해 볼 수 있습니다.

범용 프로그램 직접 써 보기

선박 데이터 하나만 다루면 프로그램이 그 데이터에만 묶이게 됩니다. 같은 신경망 알고리즘을 어떤 공개 데이터에도 적용할 수 있도록 범용 프로그램을 따로 만들었습니다. 웹페이지와 Colab 범용 코드 모두 같은 순서로 동작합니다.

1. 동작 순서

단계 하는 일 처리 방법
1. 파일 읽기 CSV, 엑셀(xlsx) 파일을 불러옴 먼저 UTF-8로 읽고, 한글이 깨지면 공공데이터에 흔한 cp949(EUC-KR)로 다시 읽음
2. 숫자 열 찾기 학습에 쓸 수 있는 열을 자동 선별 값의 90% 이상이 숫자인 열만 표시, "1,234"처럼 쉼표 들어간 숫자도 숫자로 변환
3. X, Y 선택 사용자가 입력 열과 예측할 열을 고름 입력 X는 여러 개 선택 가능, Y로 고른 열은 X에서 자동 제외
4. 정리 빈칸이나 문자가 섞인 행 제거 선택한 열 중 하나라도 숫자가 아니면 그 행을 제외
5. 정규화·분리 열마다 0~1로 정규화, 80% 학습 / 20% 테스트 선박 프로그램과 같은 Min-Max 정규화
6. 신경망 구성 입력 노드 수를 고른 X 개수에 맞춤 입력층 노드 = X 개수, 은닉층 Dense(시그모이드), 출력층 Dense(1)
7. 학습·비교 신경망과 선형회귀를 같은 데이터로 학습 신경망은 경사하강법(Adam), 선형회귀는 최소제곱법
8. 결과 표시 그래프와 테스트 R² 표시 입력 1개면 데이터 위에 예측 곡선, 2개 이상이면 실제값 vs 예측값 그래프
9. 직접 예측 원하는 값을 넣어 예측 X 개수만큼 입력 칸이 자동 생성, 학습 범위 밖의 값이면 경고

2. 입력 개수에 따라 바뀌는 신경망

선박 프로그램은 입력이 길이·너비·깊이 3개로 고정이지만, 범용 프로그램은 사용자가 고른 열 개수 m에 따라 입력층이 바뀝니다. 강의자료의 "인공신경망의 기본 틀"에서 입력 x₁ ~ xₘ이 m개인 경우를 그대로 구현한 것입니다.

은닉 노드 j의 계산: zⱼ = wⱼ₁x₁ + wⱼ₂x₂ + … + wⱼₘxₘ + bⱼ　→　σ(zⱼ)

학습되는 값의 개수도 m에 따라 달라집니다. 은닉 노드가 H개일 때 m×H + H + H + 1개이며, 웹페이지의 구조도와 개수 표시가 선택에 맞춰 자동으로 바뀝니다.

3. 정확도 지표: 결정계수 R²

데이터마다 단위와 크기가 달라 오차(MSE) 값만으로는 잘 맞았는지 판단하기 어렵기 때문에, 범용 프로그램은 결정계수 R²로 비교합니다.

R² = 1 − Σ(y − ŷ)² / Σ(y − ȳ)²

1에 가까울수록 정확하고, 0이면 모든 값을 평균으로 예측하는 것과 같은 수준입니다. 학습에 쓰지 않은 테스트 데이터 20%로 계산합니다.

4. 실행 예시

정리된 울산항 선박 데이터(3,000척 표본)를 올리고 X = 선박길이·선박너비·선박깊이, Y = 총톤수로 실행한 결과, 테스트 R²는 인공신경망 약 0.97, 선형회귀 약 0.80으로 선박 전용 프로그램과 같은 경향이 나왔습니다. 이는 범용 프로그램이 전용 프로그램과 같은 알고리즘으로 올바르게 동작함을 보여 줍니다.
